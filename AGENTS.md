# Agents working in this repo

These rules bind every contributor here, human or agent. They exist because this board carries real addresses and real hours that real people act on.

## Evidence first

- A listing enters or stays on the board only with a check against the provider's own published page. The check is logged in checks.json in the same change.
- No listing, time, address, or phone number is ever written from memory, from an aggregator, or from a search snippet. If the provider page does not say it, the listing does not say it.
- Numbers in the README (listing counts, verified counts, dropped counts) come only from the logged checks and the current listings.json. Recount before you restate them.

## No medical claims

- Ground lists services. It does not describe outcomes, quality, or who should use a service. It makes no health claims of any kind.
- Still, the sister exhibit for Layer 1, is a quiet practice tool, not medical care. Nothing in this repo suggests otherwise.

## The expiry rule

- Every listing carries verified and expires dates, 30 days apart.
- A check updates both dates and adds a row to checks.json with the checker's name, stage name, or handle.
- Never delete a stale flag quietly. A listing that cannot be rechecked is removed in a commit that says why.

## Style

- Plain short sentences. Visual first, minimal text.
- No em dashes or en dashes in any copy.
- One improvement per pull request, with the check or run attached.
